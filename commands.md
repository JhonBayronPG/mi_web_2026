# comandos basicos de git

## conocer el estado de mi work directory

´git status´

# agregar archivos o directorios a la pila de git
´git add .´ TODO
´git add -a´ TODO
´git add nombre_archivo´ un archivo
´git add nombre_archivo otro_archivo´ varios archivos
´git add nombre_directorio´ directorio

## confirma los cambios 
´git commit -m "mensaje descriptivo"´

## conocer el historial del proyecto

´git log´

# HTML
